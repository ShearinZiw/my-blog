# 嵌入式岗位知识地图

这张地图解决三个问题：今天学什么、面试官会怎样继续问、怎样把答案落到自己的项目。

## 能力分层

| 层级 | 你能做到什么 | 面试中的表现 |
| --- | --- | --- |
| L1 术语 | 说出定义和 API | 能回答“是什么”，追问即断 |
| L2 机制 | 画出时序、状态与数据流 | 能解释“为什么” |
| L3 工程 | 根据约束做选择 | 能回答“为什么这样做而不是另一种” |
| L4 诊断 | 用证据缩小故障范围 | 能完整复盘一次线上/板端问题 |
| L5 体系 | 建立接口、测试和演进边界 | 能讨论架构、量产与长期维护 |

## 第二阶段：五条主干

1. [C 工具链]({{< relref "../embedded/c-toolchain.md" >}})：预处理、编译、汇编、链接、ELF、ABI、启动与调试证据。
2. [MCU]({{< relref "../embedded/mcu.md" >}})：启动、中断、时钟、外设、DMA、Fault 与低功耗。
3. [RTOS]({{< relref "../embedded/rtos.md" >}})：任务、调度、同步、ISR 边界、实时性和内存。
4. [Linux / 驱动]({{< relref "../embedded/linux-driver.md" >}})：启动链、设备树、设备模型、中断、并发和用户态接口。
5. [lwIP]({{< relref "../embedded/lwip.md" >}})：线程模型、pbuf、TCP 生命周期、零拷贝、超时与抓包。

## 第三阶段：公司专题

- [乐鑫 Connectivity]({{< relref "../company/espressif-connectivity.md" >}})：Wi-Fi/BLE 配网、事件驱动、重连、共存、功耗与 OTA。
- [高通 / 联发科 Linux BSP]({{< relref "../company/linux-bsp.md" >}})：Yocto 分层、启动链、DT、板级 Bring-up、量产升级与公开/闭源边界。

## 复习闭环

每个知识点用同一节奏：

1. 30 秒口述结论；
2. 3 分钟画机制图；
3. 用一个项目约束解释方案选择；
4. 给出至少两个观测点和一个反证；
5. 写成卡片并在 1、3、7、14 天回忆。

## 项目追问模板

- 当时的硬约束和成功标准是什么？
- 数据从哪里来，经过哪些上下文，最终到哪里？
- 哪些资源由谁拥有，在哪个状态释放？
- 最坏时延、峰值内存和错误恢复边界是多少？
- 你用什么证据排除了硬件、配置、并发和协议问题？
- 如果流量、设备数或运行时长扩大十倍，先坏在哪里？

## 快速入口

- 只剩一天：每条主干读“核心问答”和“易错纠偏”。
- 只剩一周：完成五条主干的最小实验，并为两个项目补齐证据集。
- 准备投递：把目标 JD 的每个动词映射到一条主干和一项可验证产出，删掉无法被追问的空泛描述。
